Vice Heat is an original top-down open-city action game set in the sun-soaked
coastal city of Costa Azul. On foot or behind the wheel, you roam a full road
grid with traffic, pedestrians, palm-lined avenues and a beach along the south
shore. Steal cars, run a three-mission story chain — First Wheels, Hot Cargo
and Cool Down — earn cash, and shake off a five-star wanted system with police
cars and officers in pursuit. Get caught and you are busted at the station;
get flattened and you wake up at the hospital. Everything is drawn in code on
a canvas — no art assets, no libraries, just vanilla JavaScript.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ in a browser. Move with WASD or the arrow
keys, hold Shift to run, press E to enter or leave a car, aim with the mouse
and click to shoot, and pause with Esc or P. To build the submission dossier
instead, run `node main.ts` and read the generated `dossier.json`.
